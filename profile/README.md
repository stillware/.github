## Principles
 
- **Privacy first.** We collect as little data as a project can work with, and we say plainly what a project handles.
- **Open source.** The code is public, licensed under a free software license, and open to inspection.
- **Honest by design.** Projects state what they do and what they do not do. No hidden tracking, no remote code.
